Market Alert PC 개인정보 안내

적용 버전: PC 1.0.0 · 2026년 10월 26일

이 PC에 저장되는 정보

선택한 종목, 화면 설정, 창 위치와 크기, 직접 입력한 종목별 보유 수량·평균 매수가·현금은 Windows 사용자 프로필의 앱 데이터 폴더에 저장됩니다. PC 앱은 이 보유 기록을 서버에 업로드하거나 모바일 계정과 자동 동기화하지 않습니다.

시장 데이터와 광고

가격, 전략 상태와 시장 지표를 표시하기 위해 기존 Market Alert의 종목별 공개 데이터 서버에 연결합니다. PC 하단 광고는 카카오 AdFit 웹 광고를 사용합니다. 광고 요청에는 해당 서비스가 처리하는 일반적인 접속 정보나 쿠키가 사용될 수 있습니다. 실제 광고 제공은 광고 서비스의 정책과 게재 상태에 따릅니다.

기존 전체 웹앱

‘전체 웹앱 열기’에서 제공하는 계정 로그인·보유 정보·결제·알림 기능에는 해당 종목 웹앱의 개인정보처리방침과 이용 조건이 적용됩니다. PC의 로컬 보유 기록과 웹앱 계정 데이터는 서로 별개입니다.

삭제와 문의

앱 삭제 시에도 재설치 편의를 위해 로컬 설정이 남을 수 있습니다. Windows 앱 데이터 폴더의 market-alert-desktop 폴더를 삭제하면 로컬 기록을 지울 수 있습니다. 문의는 다운로드 페이지에 연결된 GitHub 저장소의 이슈를 이용해 주세요.
